---
title: "Retrieve API Keys"
---

Once your Grain account is set up, you'll receive an invitation email to define a password and login to your Grain dashboard. In the dashboard Settings section you can switch between the Sandbox environment, which is designated for testing purposes, and the Live environment.

In the Dashboard's left side menu, you'll find a 'Developer' section which contains two items:

- **API keys** - here you'll find your Grain authentication credentials, via [HTTP Basic authentication](https://developer.mozilla.org/en-US/docs/Web/HTTP/Authentication). Client ID is the partner username and Secret is the partner password. Note that each environment mode has a different **Client ID** and **Secret**.
- **Docs** - a link to the dedicated documentation portal walking you through the details of the Grain API.
