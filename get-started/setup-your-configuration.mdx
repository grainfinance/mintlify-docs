title: "Setup Your Configuration"
---

<Note>
  Configuration is set up together with your Grain contact, not through the API. To test in Sandbox you only need the minimal setup below; the full configuration is completed when you go live.
</Note>

To start testing in Sandbox — through both the dashboard and the API — you only need:

- At least one currency pair.
- A wallet, in a currency of your choice.
- A settlement type — Full Settlement or Offset Settlement. See [Settlements](/concepts/settlements). That's enough to create your first customer and book your first hedge. If you'd like to test more scenarios, ask your Grain contact to set up additional pairs or currencies.
